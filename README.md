# Kaybolan Çorapların İntikamı

## Bu Proje Nedir?

Bu, insanlık tarihinin en büyük gizemlerinden birini çözmek için tasarlanmış, **aşırı ciddi** ve bilimsel bir simülatördür. Çoraplarınız neden kayboluyor? Cevap basit: Çoraplar intikam alıyor. Siz onları çamaşır makinesine attığınızda, onlar da sizi terk ediyor. Bu kod, o intikamı öngörür, analiz eder ve size dramatik bir şekilde bildirir.

### Özellikler:
- Rastgele çorap kaybı tahminleri (tamamen bilimsel, güvenin)
- Abartılı varoluşsal kriz mesajları
- Çorapların sizin hakkınızda ne düşündüğünü açıklayan derin analizler
- Hiçbir şey çözmez ama çok ciddi görünür

## Nasıl Çalışır?
Python scriptini çalıştırın. O size "kaybolacak" çorabı söyleyecek. Gerçek hayatta da deneyin, bakalım haklı mı çıkacak. (Spoiler: Çıkmayacak, ama eğlenceli.)

```bash
python corap_intikami.py
```
